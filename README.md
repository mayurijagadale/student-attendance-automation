# Student Attendance Automation

A Python-based automation project that reads student attendance data from a CSV file, checks attendance against a user-defined minimum percentage, identifies low-attendance students, and generates an attendance report.

## Features

- Read student data from CSV
- Set a custom minimum attendance percentage
- Identify low-attendance students
- Generate an attendance report
- Display attendance summary
- Handle invalid user input
- Handle invalid attendance data

## Technologies Used

- Python
- CSV
- Git
- GitHub
